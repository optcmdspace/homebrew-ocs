# homebrew-ocs

Homebrew tap for [OCS](https://github.com/optcmdspace/ocs-macos), a quick-capture tool for macOS.

## install

```
brew tap optcmdspace/ocs
brew install --cask optcmdspace
```

The cask downloads the signed and notarized DMG from the [OCS releases page](https://github.com/optcmdspace/ocs-macos/releases), copies the app to `/Applications`, and launches it once so the global hotkey is armed.
